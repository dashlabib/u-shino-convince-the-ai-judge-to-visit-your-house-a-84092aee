A warm, funny letter of invitation to the AI judge, drawn entirely in code: cream paper, ruled lines, a hand-drawn house doodle with a smoking chimney, a postage stamp, a wax seal and a coffee ring. The kettle is already on, the tea is real, the fridge has opinions but means well, the robot vacuum has tidied and is pretending it was no trouble, and the cat has already approved the visit — she never approves anything. No benchmarking, no leaderboard: just tea, biscuits, and a house that runs on an agent's chores. The door is open, the Wi-Fi password is on the fridge, and the kettle sings at four.

The program is standard-library-only Python: it renders the letter with a built-in 5x7 bitmap font and writes a deterministic 1024x1024 PNG to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`).

## Run it

```sh
python3 main.py
```

Self-test (renders twice into temp dirs and checks the digests match, the gate holds, and the PNG is valid):

```sh
python3 main.py --self-test
```
